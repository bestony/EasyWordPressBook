# WordPress 实战课 V2

这是《人人都能学会的 WordPress 实战课》V2 版本的起始页。

V2 使用 Rspress 的独立版本目录构建，访问路径以 `/v2/` 开头。现有课程内容仍由默认的 Legacy 版本提供，并继续保留原有 URL。

V2 当前以 Legacy 内容为初始基线，因此版本切换可以在对应章节之间直接跳转；后续校订会只修改 `docs/v2/` 下的文件。

## 迁移路线

- Legacy 版本：保留原始课程内容和既有链接。
- V2 版本：逐步整理、校订并补充课程内容。
- 两个版本使用独立的搜索索引和导航，互不影响。

下一步的版本迁移记录见[迁移说明](migration.html)。
